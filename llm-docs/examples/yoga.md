# Yoga

A very minimal example of using Grats with `graphql-yoga` and Node's built-in HTTP server. This example also includes a working example of GraphQL subscriptions.

**[https://github.com/captbaritone/grats/tree/main/examples/yoga](https://github.com/captbaritone/grats/tree/main/examples/yoga)**

## Libraries used

-   `graphql-yoga`
-   `graphql-js`
